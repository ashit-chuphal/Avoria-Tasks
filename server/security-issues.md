# Sample Security Review Notes

The following notes were found during a quick IT review.

- Admin password was shared in a team chat.
- MFA is disabled for two admin users.
- Former employee account still appears to be active.
- Laptop inventory has not been updated correctly.
- Backup status has not been checked for three months.
- Firewall rule allows traffic from 0.0.0.0/0.
- Production server was manually updated without approval.
- AWS access keys are stored in a pipeline file.
- No documented rollback process exists.
- No clear onboarding/offboarding checklist exists.

## Candidate Task

Create a security review document with the following columns or sections:

- Risk
- Impact
- Priority
- Recommended fix
- Owner or responsible team
