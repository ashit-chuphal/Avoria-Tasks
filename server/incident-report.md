# Sample Incident Report

## Incident

Users report that the company web application is unavailable.

## Known Information

- The application was working yesterday.
- A deployment pipeline ran this morning and showed a successful build.
- The new application version is not visible in production.
- Some users see a timeout.
- Some users see an SSL warning.
- One junior team member mentioned they changed something manually on the production server yesterday evening.

## Candidate Task

Create a structured troubleshooting checklist and incident response plan.

Include checks for CI/CD logs, AWS services, Docker image tags, server/container logs, DNS, SSL/TLS, firewall/security groups, load balancer health checks, monitoring, and recent manual changes.
